# LinkedIn Browsing & Pacing Rules

LinkedIn uses automated behavioral fingerprinting to detect bot activity. Following these pacing and navigation rules ensures safe, human-like interaction.

## 1. Natural Timing & Pauses
- **Page Load:** Wait 2–4 seconds after a page loads before taking any action.
- **Before Typing:** Pause 1–2 seconds before typing into any input or message box.
- **Hover:** Hover over a conversation or button for 0.5–1 second before clicking.
- **Typing Style:** Type character-by-character; for longer messages, pause 1–2 seconds mid-text.
- **No Mechanical Delays:** Never add artificial waits between trivial non-interactive steps. Keep natural cadence.

## 2. Navigation Patterns
- **Do not open `/messaging/` directly:** Start on `https://www.linkedin.com/feed/`, wait 2–3 seconds, then navigate to Messaging.
- **Click rather than direct URL navigation:** Navigate within LinkedIn via UI elements whenever possible.
- **Search:** Use the LinkedIn search bar by typing, rather than constructing direct search query URLs.

## 3. Interaction & Scrolling
- Scroll down slightly before interacting with conversation lists.
- Scroll targets smoothly into view before clicking.

## 4. Session Operational Limits
- **Conversations per session:** Open no more than **5** conversations in one session.
- **Session Duration:** Keep active session time under **20–25 minutes**, then go idle or close.
- **One action per HR turn:** Read OR send in a given turn — never chain multiple messages.
- **No Repeat Visits:** Avoid repeatedly opening the same HR conversation in the same session.

## 5. Security & Safety Flags
- If LinkedIn displays a **CAPTCHA** or **"unusual activity"** checkpoint, **STOP IMMEDIATELY**.
- Alert the user and do not attempt automated bypass.
